# 🎌 動畫歌曲猜猜看

聽一段日本動畫的 OP／ED／劇場版主題曲，從四個選項中猜出是哪一部動畫。音樂來源為 YouTube（IFrame Player API）。

## 玩法

- **難度**：簡單（15 秒）／普通（10 秒）／困難（5 秒）
- **片段位置**：取自 YouTube「重播次數最多」熱度圖中熱度最高的段落（已排除影片開頭）；少數沒有熱度資料的影片改用隨機段落
- **題數**：5、10、20 題
- **題庫**：全部、經典（～2009）、近年（2010～），共 85 首、68 部作品
- 同一部作品的不同歌曲不會同時出現在選項中
- 計分：答對 100 分 + 速度加分（最多 100）+ 連擊加分；各難度最高分存在瀏覽器中
- 快捷鍵：`1`–`4` 作答、`R` 再聽一次、`Enter` 下一題
- 影片全程隱藏、只播放聲音；作答後揭曉作品名、曲名與歌手並繼續播放音樂，附 YouTube 連結
- **分享成績圖**：結算頁可產生 IG 限時動態尺寸（1080×1920）的成績圖，含 QR Code
- **邀請朋友挑戰**：產生挑戰連結（`?d=難度&q=題目索引&s=分數&c=答對數&n=名字`），朋友打開後用同一組題目、同樣難度作答，結算時顯示勝負。因為連結用的是 `songs.js` 的索引，新增歌曲請只加在陣列最後面

## 本機執行

YouTube 嵌入播放需要透過 http 開啟（直接開 `file://` 可能無法播放）：

```powershell
python -m http.server 8000
```

然後開啟 <http://localhost:8000>。部署：GitHub Settings → Pages → 選擇 `main` 分支。

## 檔案

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 頁面結構（開始／遊戲／結算三個畫面） |
| `style.css` | 樣式，支援手機版 |
| `game.js` | 遊戲邏輯與 YouTube 播放控制 |
| `share.js` | IG 成績分享圖 |
| `songs.js` | 題庫：台灣譯名、日文原名、曲名、歌手、年份、類型、YouTube 影片 ID、熱門片段 |
| `tools/` | 題庫製作工具：候選清單、搜尋可嵌入影片、瀏覽器播放檢查 |

## 新增題目

在 `songs.js` 的 `SONGS` 陣列**最後面**加一筆：

```js
{"zh":"台灣譯名","en":"日文原名","track":"曲名","composer":"歌手","year":2024,"type":"op","youtubeId":"影片ID"}
```

`type` 為 `op`、`ed` 或 `movie`。同一部作品的 `en` 必須一致（用來判斷答案與避免重複選項）。影片必須允許嵌入播放；若之後被下架或禁止嵌入，遊戲會自動跳過換下一首。
